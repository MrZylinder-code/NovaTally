# Planungsdokumente

Diese Dateien beschreiben, wie Spielzeit entstanden ist:

- [GOAL.md](GOAL.md): die verbindliche Zielbeschreibung (Muss-Anforderungen, Nicht-Ziele, Abnahmekriterien)
- [UEBERGABE.md](UEBERGABE.md): der technische Bauplan (Architektur-Entscheidungen, Datenbank, API, Diagramm-Regeln)

Sie sind hilfreich, um zu verstehen, *warum* etwas so gebaut ist, etwa warum es kein pywebview gibt
oder warum der Server einen Pflicht-Header verlangt. Bei größeren Änderungen bitte prüfen,
ob sie noch zu den Nicht-Zielen in `GOAL.md` passen.
